# Guanajuato-Tour
Pagina sencialla para mostrar las zonas turisticas de Guanajuato
# Reto de Despliegue Web

## Tecnologías usadas
- HTML5
- CSS3 (Minificado)
- JavaScript (Minificado)
- Servidor Web: [Nginx / Apache] (Elige el que usaste)

## Estructura del proyecto
- `/css`: Hojas de estilo.
- `/js`: Scripts.
- `/img`: Recursos gráficos optimizados.

## Proceso de despliegue
1. Se organizaron los archivos en carpetas.
2. Se minificaron los archivos CSS y JS para optimizar la carga.
3. Se generó un paquete `.zip` con el proyecto final.
4. Se configuró un [Virtual Host / Server Block] para servir la aplicación en la ruta simulada `http://localhost/tuapp`.

## Cómo ejecutarlo localmente
1. Descarga el repositorio.
2. Coloca la carpeta en el directorio raíz de tu servidor web (`htdocs` en Apache o `/var/www/html` en Nginx).
3. Aplica la configuración del servidor correspondiente.
4. Abre tu navegador y visita `http://localhost/tuapp`.
